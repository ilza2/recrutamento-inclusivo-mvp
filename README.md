# Recrutamento Inclusivo

## Sobre o projeto
O Recrutamento Inclusivo é um MVP de uma plataforma que busca facilitar o acesso de jovens a informações sobre cursos, capacitações profissionais e oportunidades de emprego.

## Objetivo
Reunir informações sobre formação e trabalho em um ambiente simples, organizado e acessível, aproximando jovens de oportunidades de desenvolvimento pessoal e profissional.

## Público-alvo
Jovens que buscam qualificação, aprendizagem e oportunidades de inserção no mercado de trabalho.

## Funcionalidades demonstrativas
- Apresentação da proposta do projeto.
- Seção de cursos e capacitações.
- Seção de oportunidades profissionais.
- Formulário demonstrativo de contato.
- Layout responsivo e recursos básicos de acessibilidade.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências.

## Observação
Os cursos e as vagas apresentados são exemplos ilustrativos. O formulário funciona apenas como demonstração no navegador e ainda não envia dados para um servidor.
